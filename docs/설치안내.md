# 휴대폰으로 Galaxy Watch에 설치하기

현재 파일은 Play 스토어 등록 전 개발용 APK입니다. 워치 실기기에서 검증하지 않았으므로 개인 시험용으로 설치해주세요. 워치9의 메뉴 이름은 One UI 버전에 따라 달라질 수 있습니다.

## 준비할 파일

- `oganeungil-watch-0.1.2.apk`: **워치**에 설치
- `oganeungil-phone-0.1.2.apk`: **휴대폰**에 설치하는 설정 앱

휴대폰 설정 앱만 설치해도 워치 앱이 자동 설치되는 방식은 아닙니다. 워치 APK는 아래 방법으로 별도로 보내야 합니다.

## PC 없이 설치

1. 휴대폰에 두 APK를 다운로드합니다. 휴대폰용 APK를 열어 ‘오가는 길 설정’을 설치합니다. Android에서 해당 파일 앱의 설치 허용을 요청하면 선택합니다.
2. 휴대폰과 워치를 같은 Wi-Fi에 연결합니다. Galaxy Wearable에서도 연결되어 있어야 합니다.
3. 휴대폰에 [Wear Installer 2](https://play.google.com/store/apps/details?id=org.freepoc.wearinstaller2)를 설치합니다. 외부 개발자가 제공하는 ADB 설치 도구입니다.
4. 워치 **설정 → 워치 정보 → 소프트웨어 정보 → 소프트웨어 버전**을 여러 번 눌러 개발자 옵션을 활성화합니다.
5. 워치 개발자 옵션에서 **ADB 디버깅**, **무선 디버깅**을 켭니다.
6. Wear Installer 2에 워치 IP를 입력하고 메뉴의 **Pair with watch**를 선택합니다. 워치의 **새 기기 페어링** 화면에 표시되는 코드·페어링 포트로 연결합니다.
7. 연결 후에는 무선 디버깅 메인 화면의 **연결 포트**를 입력합니다. **페어링 포트와 연결 포트는 서로 다릅니다.**
8. Wear Installer 2의 **Custom APK**에서 `oganeungil-watch-0.1.2.apk`를 선택해 설치합니다. 휴대폰용 APK를 고르지 마세요.
9. 설치가 끝나면 워치의 무선 디버깅·ADB 디버깅을 끕니다. 이후 일반 사용에는 필요하지 않습니다.

설치 도구의 현재 단계별 설명은 [제작자 안내](https://freepoc.org/wear-installer-2-help-page/), 워치 개발자 모드 설정은 [삼성 안내](https://developer.samsung.com/health/sensor/guide/connect-watch.html)를 참고하세요. 워치9에서 이 설치 도구와의 직접 연결 검증은 아직 하지 못했습니다.

## 타일 추가

워치 타일 화면에서 끝까지 넘겨 **타일 추가 → 오가는 길**을 선택하거나 Galaxy Wearable의 타일 편집에서 추가합니다. 이 앱의 타일은 실행 버튼입니다. 타일을 눌러 실제 앱을 열면 위치를 확인하고 출근·퇴근을 판단합니다. 타일 자체는 위치를 읽거나 실시간 교통 정보를 계속 조회하지 않습니다.

## 처음 설정

- UI부터 확인하려면 휴대폰 앱에서 **시연 모드**를 켜고 **워치로 보내기**를 누릅니다. 시연 시각·버스는 실제 운행 정보가 아닙니다.
- 집·회사에 있을 때 휴대폰 앱에서 각각 **현재 위치 등록** 후 저장·전송합니다. 위치 권한이 필요합니다. 워치에도 위치 권한을 허용합니다.
- 집·회사에서 멀리 떨어져 있거나 위치 오차가 크면 자동 추측하지 않고 직접 선택합니다. 상단 시각을 누르면 출근·퇴근을 선택할 수 있습니다.
- 워치 화면을 길게 누르면 설정과 사용 방법을 볼 수 있습니다.
- 좌우 화살표는 같은 열차의 출발역·하차역 시각을 함께 넘깁니다.
- **Refresh**는 현재 시각 기준 다음 열차를 선택하고 버스도 함께 조회합니다. 위치는 다시 읽지 않습니다. 위치 재판단은 앱 재실행 또는 설정 메뉴에서만 합니다.

## 키 발급과 실제 버스 정보

1. [경기버스 키 발급 안내](https://www.gbis.go.kr/gbis2014/publicService.action?cmd=publickKey)에서 공공데이터포털로 이동합니다.
2. **경기도 버스도착정보 조회 서비스**, **경기도 버스정류소 조회 서비스** 활용 신청을 합니다. 최신 서비스 이름과 승인 상태는 포털에서 확인합니다.
3. 일반 인증키의 **Decoding** 값을 휴대폰 앱의 API 키 칸에 입력합니다. 키를 채팅에 보내지 않아도 됩니다.
4. **시연 모드를 끄고** 저장·워치로 보내기를 누릅니다. 워치가 연결되어 있지 않으면 설정 전송은 대기합니다.
5. 워치 앱을 다시 열어 Refresh를 누릅니다.

정류소 표시 번호 29275·56342·23641을 stationId로 직접 사용하지 않습니다. 정류소 조회 API에서 일치하는 mobileNo를 찾아 내부 ID를 얻습니다. 노선은 5001-1A·30·5001-1B를 정확히 대조합니다. API가 A/B 구분 이름을 제공하지 않거나 중복되면, 휴대폰 고급 설정에 올바른 내부 노선 ID를 넣어야 합니다. 이 ID들은 키를 발급한 뒤 실제 응답을 확인해야 합니다.

공식 [경기버스 도착정보 API](https://gbis.go.kr/gbis2014/publicService.action?cmd=mBusArrivalStation)는 첫 번째·두 번째 차량만 제공합니다. 따라서 **퇴근 세 번째 버스는 —**로 표시됩니다. 간격을 추측해서 세 번째 도착 시각을 만들지 않습니다. 사용자가 원한 3대 실시간 표시를 완성하려면 3대 이상을 제공하는 별도 출처가 필요합니다.

API 키의 서버 응답과 실제 노선 매칭은 아직 검증되지 않았습니다. 호출 실패·운행 정보 없음·90초 이상 지난 정보는 실제 도착 시각처럼 표시하지 않습니다.

## 실제 급행 시간표

최신 시간표를 자동으로 확보하지 못했으므로 실제 시각은 번들에 포함하지 않았습니다. [9호선 공식 시간표](https://www.metro9.co.kr/prog/subwayTm/kor/sub01_02/list.do)와 대조한 CSV를 휴대폰 앱에서 가져오고, 출처·유효기간을 입력해 워치로 보냅니다.

형식은 `day,direction,train_id,departure_arrival,destination_arrival`입니다. 양쪽 시각은 반드시 **같은 급행 열차**의 시각이어야 합니다. 고정 소요시간을 더해 만들지 않습니다.

- `DAY` 평일, `SAT` 토요일, `END` 일요일·공휴일
- `MORNING`: 신논현 도착시각 → 마곡나루 도착시각
- `EVENING`: 마곡나루 도착시각 → 신논현 도착시각
- 00시 이후 운행은 영업일 기준 `24:xx`·`25:xx` 지원
- 출처·만료일이 없거나 만료된 시간표는 표시하지 않습니다.
- 주말은 자동 판단합니다. 공휴일은 휴대폰 설정에서 날짜 목록을 입력하거나 ‘일요일·공휴일’을 직접 선택해야 합니다.

빠른하차는 사용자가 지정한 출근 2-1·4-4, 퇴근 1-1·4-4를 표시합니다.
