# 오가는 길 0.1.2 업데이트

- 워치용과 휴대폰용 APK를 각각 기존 앱 위에 덮어 설치하세요. 앱 ID와 서명을 유지했습니다.
- 공개 APK에는 API 키가 포함되지 않습니다. 휴대폰 설정에서 발급 키를 입력하고 저장하세요.
- 이전 버전의 시연 모드는 업데이트 후 실제 조회 모드로 바뀝니다. 집·회사 위치와 기존 시간표는 유지합니다.
- 휴대폰의 ‘워치로 보내기’를 누르고 워치에서 Refresh를 누르세요.
- HTTP 오류/시간 초과/인증/호출 한도를 구분해 표시합니다.

실행 환경에서 공공데이터 API 연결이 HTTP 503(상위 서버 연결 시간 초과)으로 끝나 실제 도착 응답은 확인하지 못했습니다. 이는 승인 완료 여부를 판정한 결과가 아닙니다. 워치 실제 실행 결과를 확인해야 합니다.

지하철 실제 시간표 등록은 여전히 별도이며, 공식 경기버스 API가 제공하지 않는 세 번째 차량은 —로 표시됩니다. API 키는 앱의 휴대폰 설정에서 입력하세요. `.env` 파일, 서명 키, 집·회사 위치는 GitHub에 올리지 마세요.
